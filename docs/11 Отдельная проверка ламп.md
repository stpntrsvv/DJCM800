# Отдельный стенд подробных ламповых законов

Поручение 2026-09-10: исследовать более подробные законы ламп отдельно от усилителя.
Ветка `research/detailed-tube-validation`; программа `simulation/run_tube_validation.py`,
законы `simulation/tube_models.py`, [результаты](../simulation/experiments/detailed_tubes/report.md).

## Выбор кандидатов

Для EL34 реализована модель Reefman с зависимостью экранного тока от анодного
напряжения, перераспределением токов и вторичной эмиссией. Коэффициенты взяты
без подгонки из авторской `TubeLib.inc`, блок EL34 от 15.12.2013. Библиотека
помечена 26.12.2025 и извлечена из текущего авторского MSI, без запуска программы.
Имя базового блока `BTetrodeD` историческое: его рациональная зависимость от Va
соответствует пентодному варианту; экспоненциальный вариант называется `BTetrodeDE`.
Не следует выбирать физическую топологию по имени программного блока.

Для ECC83 реализован Dempwolf–Zölzer с отдельными токами катода и управляющей
сетки, анодный ток равен их разности. Использованы все три опубликованных набора
коэффициентов RSD-1/RSD-2/EHX-1. Это параметры измеренных экземпляров 12AX7,
а не подбор под Philips и не измерения ламп конкретного Marshall.

Ссылки и хеши первичных данных: `reference/tube_validation_sources.json`.
Связанный с новой страницей файл `EM4_Theory.pdf` сам датирован 14.03.2019;
он не выдаётся за полное описание всех возможностей текущего ExtractModel 4.

## Интерфейс и численные решения

Напряжения задаются относительно катода в вольтах, токи — в амперах.
`dempwolf` возвращает `(Ia, Ig1, Ik)` и якобиан по `(Va, Vg1)`.
`reefman` возвращает `(Ia, Ig2, Ia+Ig2)` и якобиан по `(Va, Vg1, Vg2)`.
Последняя сумма не включает ток управляющей сетки и не называется полным Ik.

Вычисления float64. Softplus записан через `logaddexp`, производные аналитические.
Для Reefman сохранены авторские округлённые составные коэффициенты: их нельзя
молча пересчитывать из отдельно округлённых kg1 и kg2 и затем требовать точного
совпадения с исходной библиотекой. Отрицательные Va и неположительные Vg2 явно
отвергаются: численное продолжение для старта большой MNA ещё не выбрано.

Отдельная функция `grid_diode` точно решает статическую старую ветвь R+Shockley
через Wright omega. Это только контроль для сравнения сеточных характеристик;
она не объявляется новым физическим законом вакуумной сетки.

## Проверки и смысл результатов

- 38 SPICE-развёрток, 3590 точек. Для EL34 использованы исходные авторские
  выражения после адаптации синтаксиса ngspice; они не экспортируются из Python-закона.
- Якобианы: 105 точек трёх триодных наборов и 252 точки EL34; центральные разности
  с шагом 0,1 мВ, допуск `1e-9 А/В + 1e-5·abs(J)`.
- Обе табличные точки ECC83 и обе колонки класса A EL34 из Philips проверены
  по изображениям. Vs=245 В второй колонки выведено из указанного экранного тока.
- Экранный резистор 2 кОм проверен отдельным связанным статическим расчётом.
- Отдельно исследованы низкое Va с положительной сеткой, глубокая отсечка,
  изменение экрана и точка напряжений прежнего покоя усилителя.

Совпадение с ngspice подтверждает реализацию закона, но не точность лампы.
Новый экранный ток EL34 ближе к двум точкам Philips; анодные токи всё ещё отличаются.
Триодные наборы не проходят точное совпадение с обоими номинальными режимами Philips.
При низком Va модель Dempwolf сохраняет существенный Ia с положительной сеткой.
У Reefman найдены обратные анодные токи в глубокой отсечке при высоком экране;
вторичная эмиссия допускает такой знак, но конкретные величины пока не проверены
независимыми данными. Результаты сохранены без ограничения токов и подгонки.

## Что пока не сделано

Сырые измеренные семейства EL34 в авторском пакете не найдены. Сравнение с полной
поверхностью измерений, положительный Ig1 EL34, проверка динамики зарядов и ёмкостей
остаются открытыми. Ёмкости из Philips не всегда совпадают с использованными
в предыдущем прототипе: например, для ECC83 на листе 1970 указаны 1,6 пФ
анод–сетка и существенно меньшая ёмкость анода ко всем электродам кроме сетки.
Изменение ёмкостей должно стать отдельным контролируемым опытом.

Полная схема пока использует прежний закон. Чтобы заменить его, нужны:

1. Независимые данные семейств и выбранная цель: типичная Philips или конкретный
   измеренный экземпляр, без смешения разных ламп в одном наборе коэффициентов.
2. Проверка фактических диапазонов Va/Vg1/Vg2 в каскадах усилителя и обоснованное
   поведение модели на старте и пробных точках Ньютона.
3. Отдельное подключение в MNA с удалением прежней сеточной ветви там, где новый
   закон уже считает Ig1; иначе возникнет двойной сеточный ток.
4. Повторное установление питания, энергетический баланс и сгущение сетки перегруза.
   Старое принятое состояние после изменения ламп использовать нельзя.

Запуск на этой машине:

```sh
.venv/bin/python reference/fetch_tube_validation.py
.venv/bin/python simulation/run_tube_validation.py
```

Установлены локальная `.venv`, ngspice 47 и 7zz для распаковки источников.
Общий старый `fetch_sources.py` остановился на изменённом SHA-256 HTML-страницы
Koren; новая программа восстанавливает нужные этому опыту источники независимо,
с проверкой каждого хеша. Исходные сохранённые хеши не изменялись.
