# Кандидаты моделей ламп

## Продолжение 2026-09-10

Оба кандидата реализованы в отдельном `simulation/tube_models.py` и проверены
стендом `simulation/run_tube_validation.py`. Для Reefman взяты коэффициенты
авторской EL34, для DZ — все три набора статьи. Новой моделью усилителя
они пока не назначены: ограничения и расхождения сохранены в
[отчёте](../simulation/experiments/detailed_tubes/report.md).
Таблица отражает актуальное состояние кандидатов.

Первый Koren-прототип нужен для запуска полной топологии. Проверка уже показала,
что его параметры нельзя принять окончательно без дополнительной работы.
Не подгоняем весь усилитель, компенсируя одну ошибку другой.

| Кандидат | Основание рассмотреть | Статус |
|:---|:---|:---|
| Norman Koren, Tube.lib 2001 | открытые авторские уравнения, ECC83 и EL34 в одном пакете | адаптирован, проверен в трёх DC-точках; есть существенные расхождения |
| Dempwolf–Zölzer, DAFx 2011 | измеренные 12AX7, отдельное внимание сеточному току, дифференцируемые законы | реализованы три авторских набора, проверены токи и якобианы; ограничение при Va<20 В сохраняется |
| Derk Reefman, теория 14.03.2019 / авторский набор EL34 15.12.2013 | модели пентодов, разделение анодного/экранного тока, связь с измерениями uTracer | реализована EL34 со вторичной эмиссией, сверена с авторской SPICE-библиотекой; физическая аттестация открыта |

[Dempwolf–Zölzer: A Physically-motivated Triode Model for Circuit Simulations](https://dafx.de/paper-archive/2011/Papers/76_e.pdf).
Статья важна именно для положительного сеточного тока и взаимодействия перегруженных
каскадов. Её параметры измеренных современных ламп не являются автоматически
параметрами исторической ECC83 в выбранном Marshall.

[Reefman: Spice models for vacuum tubes using the uTracer](https://www.dos4ever.com/uTracer3/EM4_Theory.pdf).
В документе отдельно разобраны ограничения Koren, новые пентодные модели,
анодный и экранный ток, вторичная эмиссия. Использованы разделы о пентодных токах и вторичной эмиссии;
параметры EL34 нужно привязать к выбранным данным, а не только к имени лампы.

Метод сравнения: одинаковая сетка анод/сетка/экран, токи и производные, контроль
физического диапазона; затем DC всей схемы и сильный сигнал с неизменными
пассивными номиналами. Подгонка к одному табличному току не считается аттестацией.
Ёмкости, зависимость сеточного тока от анодного напряжения и восстановление после
перегруза проверяются отдельно. Пока ни один кандидат не объявлен победителем.
