# Что переносим из маффа

Это карта уже исследованных путей соседнего проекта. Числа STM32G474 и результаты
Big Muff не являются результатами STM32N6/JCM800. Код маффа не копировался.

| Опыт маффа | Вывод для JCM800 | Где искать исходное доказательство в соседнем проекте |
|:---|:---|:---|
| Полная узловая модель и точное исключение линейных переменных | Сначала общий решатель; уменьшать число неизвестных без удаления физических связей | `complete_reduction`, `hybrid_active` |
| Малые системы вместо плотного общего решения | Использовать топологию и постоянные коэффициенты после проверки общего эталона | `cascade_solver`, `block_solver_specialization` |
| Малое приращение нелинейностей | Сохранять согласованные ток и производную, обновлять локально; для ламп отдельно проверить exp/log/степени | `q3_incremental`, `full_cached_nonlinearity`, `docs/10...` |
| Отказ Q1 на длинной DI | Численное представление должно быть обусловленным; проверка кандидата до записи состояния обязательна | `song_fault` |
| Q2 и одинаковый шаг BDF2 | Разделять точность корня и точность относительно аналоговой схемы; случайная компенсация ошибок возможна | `q2_polynomial`, `bdf2_same_step` |
| Несходимость обычного Ньютона | Повтор того же шага с демпфированием отличает отказ решателя от провала интегратора | `bdf2_same_step` |
| Разные интеграторы и частоты | BDF2, TR-BDF2, α-метод и многоскоростность сравнивать заново при одинаковой физике | `tr_bdf2`, `generalized_alpha_composed`, `port_multirate` |
| Приближённые границы блоков | Возврат нагрузки может изменить устойчивость/точность; в усилителе есть ещё глобальная ООС и общая шина питания | `boundary_correction` |
| FMAC | Аппаратный ускоритель не обязан выигрывать; учитывать подачу данных и смену контекста | `fmac_benchmark` |
| Реальный DMA и длинный аккорд | Проверять худший блок и редкие дорогие ветви, отдельно измерять ввод-вывод | `song_fault`, `composed_audio_runtime` |

Расположение отчётов: `../big-muff-stm32/simulation/experiments/<имя>/report.md`.
Машинный код, коэффициенты и периферия старого проекта не универсальны.

Ранние потенциальные ускорения JCM800: аналитическое исключение линейной сети,
устойчивые локальные законы ламп с общими промежуточными значениями для тока и
якобиана, специализация разреженного решения, проверяемое разбиение по портам.
Быстрое обновление экспоненты здесь лишь часть работы: в законе Koren присутствуют
softplus, корень, дробная степень и арктангенс. Их стоимость и локальные приближения
нужно измерить. Сеточное выпрямление и восстановление зарядов запрещают заменять
ламповую цепь безынерционным ограничителем по одному статическому графику.

Первый этап не тратим на преждевременное повторение всех оптимизаций: сначала
получаем доверие к физике большой модели и самостоятельному решателю float64.
