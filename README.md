# Marshall JCM800 — STM32N6

Физическая цифровая модель **Marshall JCM800 2203 Master Volume, 100 Вт, EL34**
по двум заводским листам **24 апреля 1981 года**. Самостоятельный проект рядом
с `big-muff-stm32`; прошивка и история маффа не изменяются.

Созданы сигнальный SPICE-прототип и собственный общий решатель MNA float64:
High Input → V1b → V1a → V2a → V2b
→ Bass/Middle/Treble → Master → V3 → четыре EL34 → выходной трансформатор
→ нагрузка 16 Ом. Presence и отрицательная обратная связь замкнуты внутри модели.
Питающие RC/LC-цепи взаимодействуют с сигнальным трактом. В расширенной модели
добавлены сетевой мост, цепь bias, связанные обмотки питания/накала и отводы OT.
Она содержит 90 узлов и 104 неизвестных, без разбиения на независимые каскады.

**Статус: исследовательский прототип, не аттестованный эталон усилителя.**
Используются модели Koren с документированными изменениями, линейный
трансформатор-аналог и предварительные магнитные/диодные параметры.
Нет модели кабинета, магнитного насыщения, теплового прогрева или прошивки STM32N6.

## Воспроизведение

Из корня этой папки, в существующей рабочей среде:

```powershell
..\.venv\Scripts\python.exe simulation\run_reference.py
..\.venv\Scripts\python.exe simulation\run_full_mna.py
```

На другой машине: Python с зависимостями из `requirements.txt`, ngspice в `PATH`
либо путь в `NGSPICE_EXE`. Программа также находит общий локальный ngspice маффа.
`--quick` выполняет один диагностический прогон и перезаписывает отчёт его результатом.
Это описание `run_reference.py`; у `run_full_mna.py --quick` два коротких опыта.
Полный новый запуск добавляет сгущение шага и 60 мс сетевого старта.

[Отчёт и графики](simulation/experiments/reference_baseline/report.md).
Сырые данные остаются в игнорируемом `simulation/raw/`.
[Аудит DC и обратной связи](simulation/experiments/reference_baseline/audit.md)
воспроизводится командой `python simulation/audit_reference.py` после полного прогона.

Проверка начальных моделей ламп: `python simulation/validate_tubes.py`;
[отчёт](simulation/experiments/tube_validation/report.md). Уже выявлены значительные
расхождения с отдельными режимами Philips; выбор моделей ещё не закрыт.

Схемы и авторские материалы скачаны в `reference/originals/` и не входят в Git.
Для восстановления: `python reference/fetch_sources.py`; список URL и SHA-256
сохранён в `reference/sources.json`. Правообладатели исходных материалов сохраняют
свои права; общий открытый лицензионный статус проекту пока не назначен.
