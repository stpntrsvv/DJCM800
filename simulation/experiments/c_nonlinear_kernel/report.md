# Float64 C-ядро нелинейностей JCM800

Статус: **pass**.

В C перенесены без смены параметров законы Dempwolf RSD-1 и Reefman EL34.
Общий примитив softplus+sigmoid использует один exp вместо двух; режим токов
не вычисляет производные, которые не нужны при проверке line search и истории.

## Бюджет одного вызова нелинейностей

В принятой схеме 6 секций ECC83 и 4 EL34. По медианам выше их C-вызов
занимает на этом CPU около **495 нс** только для токов и
**732 нс** с Jacobian. Это не полный шаг Ньютона:
сюда не входят диоды, stamping, невязка, Schur/LU и line search.

## Dense LU 39×39

На реальном масштабированном Jacobian max Δx=3.549e-08,
относительная невязка=3.646e-15. Медиана полного C solve
на текущем CPU — **10000 нс**. Статический бюджет: 19019 пар multiply-subtract, 741 делений исключения и 741 членов обратного хода.

Это корректный перенос текущей плотной алгебры, но ещё не финальная архитектура:
фиксированная разреженность позволяет затем выбросить гарантированные нули.


Это время скомпилированного C на текущем CPU, не такты STM32N6. Для оценки
микроконтроллера API отделяет число вызовов ламп от линейной алгебры; реальные
такты получаются аппаратным DWT/PMU замером того же ядра после кросс-компиляции.

Статически на одну лампу: ECC83 — 2 exp, 2 log1p и 2 pow; EL34 — exp,
log1p, pow, sqrt и tanh. В currents-only исключаются степени и операции, нужные
только производным, но физические токи вычисляются теми же формулами.
