# Полный float64 C timestep JCM800

Статус: **pass**.

В C исполняются G/C, лампы и диоды, история неявного Эйлера, RHS, residual,
Newton, line search и сгенерированный sparse98 solve. Все 98 состояний сохранены.

На 1600 шагах по 1.25 мкс: max ΔV=7.056e-08 В,
max ΔI=4.849e-10 А, ошибка выхода=1.188e-11.

Текущий Mac: 30678 нс/шаг с ctypes, ускорение к полной Python MNA
**91.4×**. Это не такты STM32N6; на плате нужен DWT/PMU замер.
