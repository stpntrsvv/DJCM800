# Сухая атака ми-мажорного аккорда

`e_major_attack.wav` — неизменённая копия тестового сигнала из соседнего проекта
BigMuffDPi: моно PCM16, 48 кГц, 250 мс.

Исходный путь на момент импорта:
`BigMuffDPi/simulation/samples/e_major_chord/e_major_attack.wav`.
SHA-256 файла: `10877cbd67e41d3e187d46b4463b82e30e1b40c6012e16bead2b0c5bf07ae1f1`.

Аккорд собран из шести сухих нот Stratocaster `E2–B2–E3–G♯3–B3–E4` проекта
[cluesurf/wavebase](https://github.com/cluesurf/wavebase), объявленных автором
общественным достоянием. Струны вступают снизу вверх с шагом 7 мс; исходный
аккорд сведён в моно, линейно пересчитан с 44,1 до 48 кГц, из него вычтено среднее
и он нормирован к −3 дБFS. Скрипт сборки остаётся в BigMuffDPi.

PCM не задаёт физического напряжения. Каждый опыт JCM800 отдельно вычитает среднее,
нормирует форму к единичному peak и назначает входной уровень в вольтах. Между
отсчётами используется линейная интерполяция, вне файла — ноль.
