# Оригинальная схема целиком

Два заводских листа Marshall, issue 1, дата **24-4-81**, вместе содержат
предусилитель, фазоинвертор, оконечник, питание, смещение и накал.

- [Оба листа в одном PDF](originals/marshall_2203_factory_1981.pdf).
- [Оригинал первого листа GIF](originals/jcm800pr.gif).
- [Оригинал второго листа GIF](originals/jcm800pw.gif).

PDF — локальная подшивка исходных изображений; соединения и номиналы на них
не перерисованы. GIF остаются оригинальными скачанными файлами с SHA-256.
Восстановление: `python reference/fetch_sources.py`, затем
`python reference/assemble_factory.py`. Скачанные материалы и PDF вне Git.

Источники: [заводской предусилитель](https://www.drtube.com/schematics/marshall/jcm800pr.gif)
и [заводской оконечник/питание](https://www.drtube.com/schematics/marshall/jcm800pw.gif).

Выбор ветвей для нашего усилителя:

| Лист | Нужная область |
|:---|:---|
| Предусилитель | нижняя левая Master Volume для 2203; справа общий Phase Splitter |
| Оконечник | нижняя 100W; номиналы EL34, без поправок USA/6550 |

Межлистовые связи:

| Метка | Назначение |
|:---|:---|
| A / A′ | питание фазоинвертора и через RC-цепи предусилителя |
| B | Master → вход фазоинвертора на том же листе |
| C / C′ | общая земля |
| D, E | выходы фазоинвертора после 22 нФ → пары управляющих сеток EL34 |
| F | отвод 4 Ом выходного трансформатора → резистор ООС 100 кОм |

Полнота чертежа не означает полноту параметров модели. Трансформаторы и дроссель
на заводском листе обозначены типами; кривые намагничивания и паразитные параметры
там не приведены. Это отдельно отмечено в `docs/09 Полная схема и общий решатель.md`.
